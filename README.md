# ChoiceInspector statistics feed

Public aggregate statistics for Slay the Spire 2, separated by exact game version and restricted to Ascension 10 standard solo runs.

Source: [Spire Codex public run exports](https://spire-codex.com/developers).

`manifest.json` lists versioned gzip datasets, SHA-256 checksums, source timestamps, and aggregation rule versions. Datasets contain aggregate counts only. This repository does not distribute the mod, its source code, raw run exports, player identifiers, or personal saves.

Updates are checked daily at 03:37 UTC (12:37 Korea time), subject to GitHub scheduling delays and source availability. Unchanged source exports do not produce a new dataset. Validation failures retain the previous published data.

Observed win rates describe the submitted public sample; they are not causal estimates of the benefit of taking an item. Synergy rules and simulation models are not updated by this feed.
